# Contributors Guide

Welcome to the SSPM Control Scraper project! Please read and follow these contribution guidelines to ensure smooth collaboration.

---

## Contribution Workflow

1. **Clone the Repository**
   ```bash
   git clone https://github.com/RishabhDev42/SSPMControlScraper.git

2. **Create a New Branch**

   * Branch names must follow the format:

     ```
     <issueNumber>_<yourGitHubUsername>
     ```

     **Example:**
     `42_janedoe`

   * This branch should relate to a specific issue or task you're working on.

3. **Make Your Changes**

   * Keep commits atomic and descriptive.

4. **Push Your Branch**

   ```bash
   git push origin <your-branch-name>
   ```

5. **Open a Pull Request (PR)**

   * Target the `main` branch.
   * Provide a clear description and reference the related issue number.
   * PRs must be reviewed and approved by **at least one other collaborator**.

6. **Get Your PR Reviewed**

   * You **cannot merge your own PR** without a peer review.
   * Once approved, you may merge the PR **if you have permissions** — or ask the project owner to merge.

---

## Naming & Enforcement

* PRs from improperly named branches (e.g., `fix-bug`, `update1`) will be **blocked by automated checks**.
* A GitHub Action will validate your branch name format before allowing merge.

---

## Best Practices

* Keep branches focused on a single change or issue.
* Run your code/test it before submitting a PR.
* Follow the Pull Request template provided in [PR.md](https://github.com/RishabhDev42/SSPMControlScraper/blob/main/.github/PR.md).
